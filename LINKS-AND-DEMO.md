## 📊 **XEM OUTPUT:**

Sau khi hoàn thành quiz:

### **1. Trong Console:**
```javascript
// Xem output đầy đủ
console.log(window.detailedQuizOutput);

// Xem từng phần
console.log(window.detailedQuizOutput.summary);
console.log(window.detailedQuizOutput.quiz_results);
```

### **2. Copy JSON:**
```javascript
QuizUtils.copyJSON();
// Paste vào text editor để xem
```

### **3. Download JSON:**
```javascript
QuizUtils.downloadJSON();
// File sẽ được download: quiz-output-TIMESTAMP.json
```

## 📱 **MOBILE TEST:**

Quiz responsive, test trên mobile:

1. Upload files lên server
2. Truy cập URL trên mobile
3. Hoặc dùng ngrok:
```bash
# Install ngrok
npm install -g ngrok

# Run local server
python -m http.server 8000
# Hoặc: php -S localhost:8000

# Expose với ngrok
ngrok http 8000

# Access từ mobile: https://xxxx.ngrok.io/example-with-ids.html
```
