🔍 Simple Network Debug

Kiểm tra xem browser có thể load file từ CDN không.

📋 Instructions:

  1. Click "Test CDN" để test kết nối CDN
  2. Click "Check Console" và nhấn F12 để xem chi tiết
  3. Nếu CDN fail → Dùng file STANDALONE-QUIZ.html
📥 File STANDALONE-QUIZ.html:
File này chứa TẤT CẢ code trong 1 file HTML duy nhất.
Không cần internet, không cần load external files.
100% chắc chắn hoạt động!
