## 🆘 **TROUBLESHOOTING:**

### **Vấn đề: Output có `ans: []` (empty)**

**Nguyên nhân:** Đang dùng file CŨ (`local_datainput.js`)

**Fix:** Dùng `local_datainput_with_ids.js`

### **Vấn đề: Output có `expl` field**

**Nguyên nhân:** Đang dùng engine CŨ (`global-quiz.js`)

**Fix:** Dùng `global-quiz-with-ids.js`

### **Vấn đề: main_total_questions = 5**

**Nguyên nhân:** File data CŨ (5 câu)

**Fix:** Dùng `local_datainput_with_ids.js` (12 câu)
