🎯 Các loại câu hỏi hỗ trợ

  • MCQ - Chọn 1 đáp án (text)
  • Multi - Chọn nhiều đáp án (text)
  • Image MCQ - Chọn 1 hình ảnh
  • Image Multi - Chọn nhiều hình ảnh
  • Hotspot - Click vào 1 điểm trên hình
  • Multi Hotspot - Click vào nhiều điểm
  • Order - Sắp xếp thứ tự bằng drag & drop
  • Image Pair - Ghép cặp hình ảnh
  • Drag Drop - Kéo thả để phân loại

💻 Cách sử dụng cơ bản

<!-- 1. Load Global CSS (bắt buộc) --> <link rel="stylesheet" href="quiz-game/global/quiz-global.css"> <!-- 2. Load Screen CSS (chỉ load loại câu hỏi bạn dùng) --> <link rel="stylesheet" href="quiz-game/screens/mcq/screen-mcq.css"> <!-- 3. Container --> <div id="quiz-container"></div> <!-- 4. Load Global JS (bắt buộc) --> <script src="quiz-game/global/quiz-global.js"></script> <!-- 5. Load Screen JS (chỉ load loại câu hỏi bạn dùng) --> <script src="quiz-game/screens/mcq/screen-mcq.js"></script> <!-- 6. Khởi tạo --> <script> const quiz = new QuizEngine(yourData); quiz.registerQuestionType('mcq', MCQHandler); quiz.init('quiz-container'); </script>
